🍕 Pizzaria API

API REST para gerenciamento de uma pizzaria, desenvolvida com Quarkus e PostgreSQL. Permite cadastrar ingredientes e pizzas (com ingredientes, tamanhos, valores e imagem).

Tecnologias
Java 21
Quarkus 3.35.4
Quarkus REST (JAX-RS) + Jackson
Hibernate ORM com Panache
PostgreSQL
Hibernate Validator
Maven (Maven Wrapper incluso)
